zev is a small command-line bridge for local scripts and agents. It runs your code through Zotero’s JavaScript API.

$ zev eval collection.js

How it works

A plugin in the running Zotero app receives code from the CLI over a local connection. Scripts use Zotero’s API to create collections, tag items, or work with attachments.

  1. Write a script

    Send a bare JavaScript statement body. The bridge wraps it in an async function.

  2. Run it with zev

    Pass a file to zev eval script.js, or pipe code through stdin.

  3. Read the result

    Return a value with return JSON.stringify(result). zev prints it in your terminal.

Install zev

You’ll need Python 3.10+, uv, and Zotero desktop. Install the CLI from GitHub and its bundled bridge plugin in Zotero.

Installation guide

  1. Install the CLI

    uv tool install git+https://github.com/akshithg/zev.git

  2. Install the bridge plugin

    zev setup --download-only

    In Zotero, open Tools → Plugins and drag in the XPI at the printed path. Restart Zotero after installing the plugin.

  3. Check the connection

    zev doctor

    Keep Zotero running when using zev eval.

Before running a script

zev is designed for a personal machine with trusted local apps. Scripts run with Zotero’s privileges, including access to your library and files. There is no sandbox or client authentication.

Review code before running it, snapshot affected data before bulk writes, and verify the result independently. A timeout does not cancel a script; check what changed before retrying.
